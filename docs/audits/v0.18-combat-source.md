# v0.18 combat-source audit

This note records the local source evidence used by the v0.18 timing pass. It applies to every runtime map: profile data has no Europe-specific branch.

## Files and fields

- `references/maps/reforged-v3-source/war3map.w3u` provides custom-object overrides. `ua1b` is base damage and `ua1c` is attack cooldown.
- `references/owned-disc-data/RoC-Units-UnitWeapons.slk` provides the inherited weapon rows. Its columns `cool1`, `dmgpt1`, and `backSw1` are cooldown, damage point, and backswing.
- `references/maps/reforged-v3-source/reforged-unit-stats.json` preserves the parsed W3U records and offsets. It deliberately labels absent custom fields `INHERITED`.
- `references/owned-disc-data/audits-v016/v016-world-unit-audit.json` is the companion cross-map audit. It confirms which values are explicit in the New World source as well; no runtime rule is selected by map.

A W3U override replaces only the named field. It does not replace inherited dice, sides, damage point, or backswing.

`UnitProfile.AttackPoint` now supplies the verified damage point to `Soldier`, so a source-profile projectile is scheduled from the same shared profile on every map. `Backswing` is retained as source metadata. ## Footman versus Ballestero

Runtime Footman is explicitly local; no active Europe W3U raw ID is asserted for it. Its current profile is 18–21 Normal/Heavy, every 1.35 seconds. It must not be represented as a source melee equivalent.

The actual source defender is `h00B` Rifleman. The base `hrif` weapon row has `dmgplus1=16`, `dice1=2`, `sides1=4`, which is 18–24 before map overrides. Europe W3U `h00B` writes `ua1b=15` (documented at `war3map.w3u@0x525`), changing only the base damage. Therefore the correct Europe `h00B` result is **17–23**, not 18–24. It retains inherited 2d4, 1.60 cooldown, .17 damage point, .70 backswing, Pierce attack, and Light runtime defence mapping.

`h012` Marine Private does not override `ua1b`; it retains the `hrif` base of 16 and is correctly **18–24**. This is why the two runtime profiles intentionally differ by one base damage point.

With the current runtime armor conversion, local Footman versus Ballestero is already stronger without a source-free buff: Footman average 19.5 damage against Light armor 0 every 1.35 s is 14.44 DPS. Ballestero average 20 Pierce damage against Heavy armor 2 is `20 / 1.12 = 17.86` every 1.60 s, or 11.16 DPS. These are runtime comparisons, not a claim that Footman has a source rawcode.

## Tower scope and unresolved data

`o000` Bunker explicitly writes `ua1c=1.5` in Europe W3U. Its inherited `otrb` row supplies 4.0 cooldown, .30 point, and .30 backswing before that map override. The live capture tower is instead the `h00N`/`h00O` city-post adapter, whose explicit .90 cooldown is preserved. Its point/backswing remain unresolved and are intentionally not guessed.

No W3U record in the inspected profiles supplies a backswing/damage point for `hdes` or `hbar`. Those values remain pending until the corresponding base object data is available in a readable, resolved source form.
